#### A / Workspace — Create, run, and verify

<a href="https://jailbrain.ai/download/workspace">
  <picture>
    <source media="(prefers-reduced-motion: reduce)" srcset="assets/workspace-map-static.png">

- Work with chat, code, images, video, and 3D in one place. Connect tasks with JAG nodes and carry knowledge forward with JBM.
- Use an **editor, terminal, Git, and debugger** in one desktop window, with AI that can read, edit, and run files in the folder you open.
- Open the interface you built, click, type, and check the result.

#### B / Alpha — From questions to sourced reports

<a href="https://jailbrain.ai/download/alpha">
  <picture>
    <source media="(prefers-reduced-motion: reduce)" srcset="assets/alpha-map-static.png">
    <img src="assets/alpha-map-motion.gif" alt="Alpha flow: classify, plan, collect, calculate, analyze, and verify. Reports link figures to sources and as-of times. This diagram does not show live market data." width="1280">
  </picture>
</a>

- Research questions about stocks, indices, crypto, and interest rates through **classify → plan → collect → calculate → analyze → verify**.
- Link report figures to a fact ledger and show their **sources and as-of times**.
- Use the research terminal, market board, and conversation history in the dedicated app. Jump between views, tickers, and conversations with `Ctrl+K` / `⌘K`.

**[Explore Alpha & download →](https://jailbrain.ai/download/alpha)** · Windows / macOS · [Still diagram](assets/alpha-map-static.png)

These motion graphics illustrate publicly described features, not live execution, market quotes, or investment performance. See the official product pages for current features and terms.

The source code for both services is private. I share my work through the live products and public overviews.
